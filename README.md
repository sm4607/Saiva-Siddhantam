# சைவ சித்தாந்தம்

> **ஞான மார்க்கம் · பக்தி மார்க்கம்**

*ஆனைமுகன் திருவருள்*

## இது என்ன?

சைவ சித்தாந்தத்தை ஆராயவும், கற்றுக்கொள்ளவும், அதில் ஆழ்ந்து ஈடுபடவும் தொடங்கப்பட்ட திட்டம் இது — **ஞான மார்க்கம்** மற்றும் **பக்தி மார்க்கம்** ஆகிய இரு வழிகளின் ஊடே.

தற்போதைய முயற்சி ஞான மார்க்கத்தில், **சிவஞான சித்தியார் — சுபக்க உரை** படிப்பில். ஒவ்வொரு பாடலுக்கும் ஒரு தனிப் பக்கம்: மூலப் பாடல், அதன் பொருள், பாடலின் பிரிவு மரம் (மனவரைபடம்), உரைக் குறிப்புகள், சொல்லிலக்கணம்.

இது ஒரு பயிற்சி; ஒரு பயணம். வழியில் கற்றுக்கொள்வதை இங்கே சேமிக்கிறோம்.

## நோக்கம்

- பாடல்களை வரிவரியாகப் படித்து, ஒவ்வொன்றின் பொருளையும் தெளிவாக உணர்வது.
- ஒரு பாடலுக்குள் அடங்கிய கருத்துகளையும், பாடல்களுக்கு இடையேயான தொடர்புகளையும் கண்டறிவது.
- கேட்டதை மறக்காமல் இருத்தல் — மனவரைபடம் நினைவூட்டும் கருவியாக இருக்கும்.
- ஞானத்தைப் பக்தியோடு இணைத்து, படிப்பை வாழ்வோடு பொருத்திப் பார்ப்பது.

## ஏன் மனவரைபடம்?

சித்தியார் பாடல்கள் எளிய சொற்களில் ஆழ்ந்த உண்மைகளைச் சொல்கின்றன. குறியீடுகள், உவமைகள், மறைபொருள் — இவை வரிவரியாகப் படிக்கும்போது தனித்தனியாகத் தெரியும்; ஆனால் அவற்றின் தொடர்பு தெரியாமல் போகலாம்.

பாடலின் பிரிவு மரம், மையக் கருத்தை நடுவில் வைத்து அதன் கிளைகளை விரிக்கிறது. எது முதுகெலும்பு, எது அதைத் தாங்கும் உறுப்பு, எது அலங்காரம் — என்பது புலப்படும்.

மனவரைபடம் படிப்பை விரைவாக்குவதற்கல்ல; **ஆழமாக்குவதற்கு**.

## குருவும் வகுப்புகளும்

இந்தப் பயணம் தனியே நடக்கவில்லை. எங்கள் குரு **இலங்கை திரு. ஜெயராஜ் அய்யா அவர்கள்** தினமும் நடத்தும் வகுப்புகளின் வழியாகவே இது நடக்கிறது. அந்த உரையே இங்குள்ள குறிப்புகளுக்கு அடிப்படை.

வகுப்புகள்: [karka.co.in](https://karka.co.in/)

## எவ்வாறு பயன்படுத்துவது

1. `index.html`-ஐ இருமுறை சொடுக்கித் திறக்கவும் — அல்லது `python3 serve.py` என இயக்கி `http://localhost:8000` திறக்கவும்.
2. முகப்புப் பக்கத்தில் இருந்து ஞான மார்க்கம் → சிவஞான சித்தியார் → பாடல் என உள்ளே செல்லலாம்.
3. ஒவ்வொரு பாடல் பக்கத்திலும்: மூலப் பாடல், பொருள், பாடலின் பிரிவு மரம், உரைக் குறிப்புகள்.
4. திரும்ப வரும்போது மனவரைபடத்தை மட்டும் பார்த்தால் போதும் — பாடல் நினைவுக்கு வரும்.

## நன்றியுரை

- எங்கள் குரு இலங்கை திரு. ஜெயராஜ் அய்யா அவர்களுக்கு — தினசரி உரைக்காக.
- [karka.co.in](https://karka.co.in/) வழியாக வகுப்புகளை எளிதாக்குபவர்களுக்கு.
- சிவஞான சித்தியார், சுபக்க உரையைத் தொகுத்து வழங்கிய அனைத்து ஆசிரியர்களுக்கும்.

## குறிப்பு

இவை தனிப்பட்ட படிப்புக் குறிப்புகள். இங்குள்ள விளக்கங்கள் குருவின் உரையைத் தழுவியவை; தவறுகள் ஏதேனும் இருந்தால் அவை என்னுடையவையே. இறுதியான பொருள் குருவின் உரையையே சாரும்.
