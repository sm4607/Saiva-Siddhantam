# சிவஞான சித்தியார் — சுபக்க உரை

> ஞான மார்க்கத்தின் மூன்றாம் நூல். தற்போது நடைபெறும் படிப்பு இதுவே — பாடல் வாரியாகப் படித்து, ஒவ்வொரு பாடலுக்கும் தனிப் பக்கம் உருவாக்கப்படுகிறது. பாடல்கள் 1–12 முடிந்தது.

மூலப் பதிப்பு: [`book/`](book/) — 1971, உரை திரு. மு. திருவிளங்கம்.

## ஒரு பாடல் பக்கத்தில் என்ன இருக்கும்

ஒவ்வொரு பாடல் கோப்புறையிலும் ஒரே கோப்பு — `index.html`. அதற்குள்ளே:

| பகுதி | உள்ளடக்கம் |
|---|---|
| மூலம் | பாடல் வரிகள், அடிக்கு அடி |
| பொருள் | உரைநடையில் பாடலின் பொருள் |
| பாடலின் பிரிவு மரம் | மனவரைபடம் — கிளைகளும் கிளைக்கிளைகளும் |
| உரைக் குறிப்புகள் | சுபக்க உரையின் ஆறு குறிப்புகளின் சுருக்கம் |
| சொல்லிலக்கணம் | அரிய சொற்களின் பொருள் |

## புதிய பாடலைச் சேர்ப்பது

1. பாடல் பக்கத்தை இதே வடிவில் உருவாக்கவும்.
2. கோப்புறைப் பெயர்: `11-<song-slug>` — எடுத்துக்காட்டாக `11-…`.
3. அந்தக் கோப்புறையில் `index.html` எனச் சேமிக்கவும்.
4. `index.html` (இந்தக் கோப்புறையின் பட்டியல்) மற்றும் முகப்புப் பக்கத்தில் ஒரு வரி சேர்க்கவும்.
