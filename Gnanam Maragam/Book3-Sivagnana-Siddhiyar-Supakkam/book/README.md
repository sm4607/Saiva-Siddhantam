# மூல நூல்

சிவஞான சித்தியார் சுபக்கத்தின் மூலப் பதிப்பு **இந்தக் கோப்புறையில் சேமிக்கப்படவில்லை** — தொகுப்பு இலகுவாக இருக்க, நூல் இணையக் காப்பகத்தில் இணைக்கப்பட்டுள்ளது.

## பதிப்பு விவரம்

- நூல்: சிவஞான சித்தியார் சுபக்கம்
- உரை: திரு. மு. திருவிளங்கம்
- வெளியீடு: யாழ்ப்பாணம் கூட்டுறவுத் தமிழ் நூற்பதிப்பு விற்பனைக் கழகம்
- ஆண்டு: 1971

## குறிப்பு

பாடல் பக்கங்களில் உள்ள மூல வரிகளும் சொற்பொருள் விளக்கங்களும் இந்தப் பதிப்பின்படியே. பக்கம் எண்கள் அதே பதிப்பைச் சுட்டுகின்றன — எனவே நூலுடன் சேர்த்துப் படித்தால் ஒப்பிட்டுப் பார்க்க எளிது.

நூல் பொது உரிமைக்காலத்தில் உள்ளதா என்பதைப் பயன்படுத்துவதற்கு முன் உறுதிப்படுத்திக் கொள்ளவும்.
