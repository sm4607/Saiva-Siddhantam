**எதிர்பார்க்கப்படும் கோப்பு:**

```
SivagananaSiddhiyaaarSupakkam-1971.pdf
```

இந்தப் பெயரிலேயே வைத்தால் நூல் பட்டியல் பக்கத்திலுள்ள **மூல நூல்** இணைப்பு நேரடியாக வேலை செய்யும்.

பாடல் பக்கங்களில் உள்ள மூல வரிகளும் சொற்பொருள் விளக்கங்களும் இந்தப் பதிப்பின்படியே. பக்கம் எண்கள் அதே பதிப்பைச் சுட்டுகின்றன — எனவே இந்த PDF உடன் சேர்த்துப் படித்தால் ஒப்பிட்டுப் பார்க்க எளிது.
