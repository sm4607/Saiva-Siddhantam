# ஞான மார்க்கம்

> அறிவின் வழி — மெய்யுணர்வை நோக்கிய பயணம்.

சைவ சித்தாந்தத்தின் ஞான நூல்களைப் படித்து, அவற்றின் கருத்துகளை மனவரைபடங்களாகவும் குறிப்புகளாகவும் சேமிக்கும் பகுதி.

## நூல்கள்

| # | நூல் | கோப்புறை | நிலை |
|---|---|---|---|
| 1 | உண்மை விளக்கம் | `Book1-Unmai-Vilakkam` | இன்னும் தொடங்கவில்லை |
| 2 | திருவருட்பயன் | `Book2-Thiruvarutpayan` | இன்னும் தொடங்கவில்லை |
| 3 | சிவஞான சித்தியார் — சுபக்க உரை | `Book3-Sivagnana-Siddhiyar-Supakkam` | பாடல்கள் 1–11 முடிந்தது |

ஒவ்வொரு நூலுக்கும் தனிக் கோப்புறை. அதனுள் ஒரு பாடல் — ஒரு கோப்புறை; உள்ளே மனவரைபடம், குறிப்புகள், பொருள் உரை.
